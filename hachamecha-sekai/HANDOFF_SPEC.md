# はちゃめちゃ世界｜引継ぎ用仕様書（HANDOFF_SPEC）

本書は「はちゃめちゃ世界」の実装済み仕様・設計原則・**絶対禁止事項**を固定化するための引継ぎ資料です。次回以降の改修・拡張時は必ず本書と `CODE_MAP.md` を最優先で遵守してください。

---

## 1. 絶対禁止事項（いかなる拡張でも実装してはならない）

1. **ガチャ禁止**（ガチャ画面・確率抽選・石・チケット等一切なし。キャラは進行・討伐条件のスカウトで加入）
2. **デイリー・ウィークリー・マンスリー禁止**（ログインボーナス・日課・リアルタイム経過タイマー待ち一切なし。派遣は戦闘勝利回数連動）
3. **PvP禁止**（ランキング・対戦・フレンド等一切なし。完全ソロ専用）
4. **オプション系ハクスラ禁止**（ランダムサブステータス・ランダム付与効果なし。装備個体差は「品質1〜100%」のみ）
5. **キャライラスト禁止（SVGイラスト含む）**（外部画像・SVG描画不使用。OS標準絵文字・記号＋CSSフレーム/オーラで表現。`assets/icon-192.png` / `icon-512.png` はPWAアプリアイコン専用）
6. **レベルシステム禁止**（Lv・EXP・経験値バー一切なし）
7. **装備強化禁止（現方針）**（+1/+2強化・素材強化なし。品質厳選のみ）
8. **図鑑ボーナス禁止**（図鑑コンプ報酬・ステータス補正一切なし。純粋な観賞用）
9. **メタ発言・設定そのまま説明文の禁止**（「戦闘はフルオートです」「1行固定」「開発中」「ガチャ無し」等のメタ文言をゲーム内テキストへ入れない）
10. **画面上半分（閲覧専用領域）への操作要素配置禁止**（`.top-viewport` は `pointer-events: none`。すべてのボタン・タブ・選択・確認・閉じる操作は下半分親指ゾーンへ配置）
11. **微妙なスクロール範囲・動的見切れ・名前「…」省略の禁止**（`100dvh`固定・ページネーション採用・固定高さカード/バフ枠/1行ログ・`text-overflow: ellipsis`不使用・自然な4〜7文字前後ネーム維持）
12. **戦闘中の他画面移動禁止**（戦闘開始時にボトムナビ5タブを `disabled` / ロックし、撤退または決着まで遷移不可）
13. **同時攻撃禁止**（行動順キューを参照し、1体の行動・演出・判定が完全に終わるまで次の1体は行動しない）
14. **ビルド成果物 `dist/` 依存の禁止**（プロジェクト直下の通常 `index.html` を `file://`・GitHub Pages・Cloudflare Pages・Capacitor `webDir: "."` でそのまま動作させる）
15. **プロジェクト総ファイル数100ファイル以内厳守**（現在34ファイル）

## 2. 技術構成・PWA・iOS対応・公開方法

- **構成**: ビルド不要・外部ライブラリゼロのピュア HTML / CSS / クラシックJS（`window.Hacha` ネームスペース分割）
- **描画**: 戦闘エフェクト層は HTML5 Canvas 2D（高DPI対応 `js/engine/battle-vfx.js`）、UIはDOM/CSS Grid＋`transform: scaleX()` による毎フレームぬるぬるゲージ
- **iOS Safari PWA ＆ セーフエリア**:
  - `viewport-fit=cover`、`apple-mobile-web-app-capable=yes`、`black-translucent`
  - `100dvh`（`100vh`フォールバック）、`env(safe-area-inset-*)` 内包、`max-height: 720px`（iPhone SE 375×667等）の最適比率切替
  - 長押しメニュー・文字選択・ダブルタップズーム・ピンチズーム無効化（セーブ入出力 `<textarea>` のみ `font-size: 16px` で入力許可）
- **オフライン・データ保存**:
  - `sw.js`（Network-First＋オフライン即キャッシュ、`http:`/`https:`のみ安全登録し `file://`/`capacitor://` では自動スキップ）
  - `IndexedDB`（`hachamecha_sekai_db`）＋ `localStorage`（`hachamecha_sekai_save_v1`）二重保存＋JSON書き出し/復元
- **将来アプリ化**: `capacitor.config.json`（`webDir: "."`, `scrollEnabled: false`）同梱済み
- **公開方法**:
  - **GitHub Pages**: `.github/workflows/deploy-pages.yml` 同梱（`main` push で自動公開）
  - **Cloudflare Pages（最も簡単な代替）**: リポジトリ連携またはフォルダのドラッグ＆ドロップのみで無料・帯域無制限・商用可公開

## 3. 実装済みゲーム仕様一覧

### 3.1 コア独自性・世界観
- **世界観混在**: 和風・スチームパンク・サイバー・深海・メルヘン重工業・神話学園グルメ・ネオン終着駅が交差する世界
- **世界法則（カオスルール）10種**: ステージごとに混線する環境ルール（`js/data/rules.js`）
- **世界共鳴シナジー15種 ＋ 共鳴チェイン**: 主力4人＋支援リンク4人の属性＆種族（**2種族持ちは両方同時カウント**）から自動発動。共鳴ゲージ100%で単独割り込み連携必殺が炸裂

### 3.2 属性・種族・ロール・厳密固定ソート
- **属性（6種）**: 炎(🔥) → 水(💧) → 風(🌪️) → 光(✨) → 闇(🌙) → 無(⚪)
  - 相性: 炎>風>水>炎（有利1.35倍 / 不利0.78倍）、光↔闇（相互1.30倍）、無（等倍安定）
- **種族（7種・2種族持ち対応）**: 人間 → 竜 → 神 → 魔物 → 妖精 → 獣 → 機械
- **ロール（4種）**: タンク(🛡️) → ディーラー(⚔️) → サポーター(🎺) → ヒーラー(💚)
- **固定並び順（`Hacha.util.compareRosterEntities`）**:
  1. 属性順（炎水風光闇無）
  2. 主種族順（人間・竜・神・魔物・妖精・獣・機械）
  3. 副種族順（単一種族 `-1` → 人間 `0` … 機械 `6`、例：`人間 → 人間・竜 → 人間・魔物`）
  4. ロール順（タンク・ディーラー・サポーター・ヒーラー）
  5. 読み仮名（`kana`）による五十音順

### 3.3 収録データボリューム
- **キャラクター24体**（全6属性×4ロール網羅・初期所持6体＋スカウト18体）：技3種（うち8体は技2＋固有パッシブ）、全技に対象範囲バッジ（単体/範囲/全体/味方単体/味方範囲/味方全体/自身/パッシブ）、全員に固有紹介文
- **敵36種**（エリア通常20・エリアボス5・乱入専用6・異界大ボス5）：全員に固有技と紹介文
- **装備42種**（武器14・防具14・装飾14）：品質1〜100%（100%＝**極品質**・1.52倍・虹金オーラアニメーション＆自動ロック）、全員に固有紹介文
- **ロール別アビリティ100種**（4ロール × 5段階 × 5択）：ロール結晶＋資金で段階解放、選択は無料自由切替
- **PvEコンテンツ5種**:
  1. はちゃめちゃ大陸（5エリア × 10ステージ ＝ 50ステージ、5WAVE）
  2. 混沌の無限塔（エンドレス階層・階層別世界法則・5階ごと大ボス）
  3. 異界大ボス討伐（5種の高難度レイドボス）
  4. 界域の試練（属性/種族出撃縛り6種）
  5. 乱入カオス襲来（乱入高確率ラッシュ4種）

### 3.4 育成＆控え活用（レベルなし）
- **基本育成**: ロールアビリティ段階解放＆5択切替、技習熟ランク（R1〜R10：実戦使用回数で自動上昇＋巻物鍛錬）
- **やり込み育成**: 異界覚醒（★0〜★5：混沌の核片）、装備の極品質（100%）厳選周回＆自動売却（初入手保護オプション付）
- **控え活用（3段構え）**: ①支援リンク（ステ18%加算＋属性/種族共鳴タグ加算）、②戦闘勝利回数連動の異界派遣（3隊×4任務・自動再派遣対応・リアル時間待ちゼロ）、③界域の試練（縛り出撃）

### 3.5 戦闘システム仕様
- 4人編成（＋支援リンク4枠）、完全フルオート、1x/2x/3x速度切替
- 通常WAVEは敵1〜4体ランダム出現、ボスWAVE以外で乱入敵が専用中央レーン警報＋赤フラッシュで乱入
- 行動順タイムライン（4体均等表示・右端切れなし）、厳格1体逐次実行（同時攻撃なし）
- バフ・デバフ・状態異常をユニットカード内固定高帯（最大6枠＋残ターン数）へ表示
- 行動ログは1行固定構造（22px・整数行切り出しで上端見切れ・折返しズレゼロ）
- DPSメーター4指標（与ダメ/被ダメ/与回復/被回復）、自動周回中は1周ごとにリセットせず累積
- 無限自動周回＆終了予約（進行中の戦闘完了後に**周回専用リザルト**へ遷移、通常戦闘は**通常リザルト**へ遷移）
- ゼロファイル Web Audio API 合成SE（ミュート切替付）
