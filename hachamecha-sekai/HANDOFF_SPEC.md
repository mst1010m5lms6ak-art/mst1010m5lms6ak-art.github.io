# はちゃめちゃ世界｜引継ぎ用仕様書（HANDOFF_SPEC）

本書は「はちゃめちゃ世界」の実装済み仕様・設計原則・**絶対禁止事項**を固定化するための引継ぎ資料です。次回以降の改修・拡張時は必ず本書と `CODE_MAP.md` を最優先で遵守してください。

---

## 1. 絶対禁止事項（いかなる拡張でも実装してはならない）

1. **ガチャ禁止**（ガチャ画面・確率抽選・石・チケット等一切なし。キャラは進行・討伐・闘技場・累計勝利条件のスカウトで加入）
2. **デイリー・ウィークリー・マンスリー禁止**（ログインボーナス・日課・リアルタイム経過タイマー待ち一切なし。派遣は戦闘勝利回数連動）
3. **PvP禁止**（ランキング・対人戦・フレンド等一切なし。完全ソロ専用。闘技場はゲーム内キャラ編成のNPC模擬戦PvE）
4. **オプション系ハクスラ禁止**（ランダムサブステータス・ランダム付与効果なし。装備個体差は「品質1〜100%」のみ）
5. **キャライラスト禁止（SVGイラスト含む）**（外部画像・SVG描画不使用。OS標準絵文字・記号＋CSSフレーム/オーラで表現。`assets/icon-192.png` / `icon-512.png` はPWAアプリアイコン専用）
6. **レベルシステム禁止**（Lv・EXP・経験値バー一切なし）
7. **装備強化禁止（現方針）**（+1/+2強化・素材強化なし。品質厳選のみ）
8. **図鑑ボーナス禁止**（図鑑コンプ報酬・ステータス補正一切なし。純粋な観賞用）
9. **メタ発言・設定そのまま説明文の禁止**（「戦闘はフルオートです」「1行固定」「開発中」「ガチャ無し」等のメタ文言をゲーム内テキストへ入れない）
10. **画面上半分（閲覧専用領域）への操作要素配置禁止**（`.top-viewport` は `pointer-events: none`。すべてのボタン・タブ・選択・確認・閉じる操作は下半分親指ゾーンへ配置）
11. **画面全体の微妙なスクロール・動的見切れ・名前「…」省略の禁止**（`100dvh`固定・下半分リスト領域のみスクロールバー非表示の縦横スクロール＋位置保持を採用・固定高さカード/バフ枠/1行ログ・`text-overflow: ellipsis`不使用・純カタカナ2〜5文字ネーム維持）
12. **戦闘中の他画面移動禁止**（戦闘開始時にボトムナビ6タブすべてを `disabled` / ロックし、撤退または決着まで遷移不可）
13. **同時攻撃禁止**（行動順キューを参照し、1体の行動・演出・判定が完全に終わるまで次の1体は行動しない。攻撃中も他ユニットのCTゲージは継続進行するが、同時発火は絶対に起きない）
14. **ビルド成果物 `dist/` 依存の禁止**（プロジェクト直下の通常 `index.html` を `file://`・GitHub Pages・Cloudflare Pages・Capacitor `webDir: "."` でそのまま動作させる）
15. **プロジェクト総ファイル数100ファイル以内厳守**（現在35ファイル）

## 2. 技術構成・PWA・iOS対応・公開方法

- **構成**: ビルド不要・外部ライブラリゼロのピュア HTML / CSS / クラシックJS（`window.Hacha` ネームスペース分割）
- **描画**: 戦闘エフェクト層は HTML5 Canvas 2D（高DPI対応 `js/engine/battle-vfx.js`）、UIはDOM/CSS Grid＋`transform: scaleX()` による毎フレームぬるぬるゲージ（CT・HP・ダメージ残像・シールド・共鳴ゲージ）
- **iOS Safari PWA ＆ セーフエリア**:
  - `viewport-fit=cover`、`apple-mobile-web-app-capable=yes`、`apple-mobile-web-app-status-bar-style=black`、`theme-color=#070b16`（旧 `black-translucent` によるiOS PWA上部強制ブラー・セーフエリア干渉を解消）
  - `100dvh`（`100vh`フォールバック）、`calc(var(--safe-top) + 6px)` ＆ 上端不透明ガード帯（`.app-shell::before`）＋ `.view-header` 独立合成レイヤ化、`max-height: 720px`（iPhone SE 375×667等）の最適比率切替
  - タップ感度最適化：CSS `touch-action: manipulation`（リスト内は `pan-y` / `pan-x`）でダブルタップズームを防ぎつつ、連続タップ硬直の原因となる `touchend` の `preventDefault()` 抑止を撤廃（ピンチズーム・長押しメニューのみ抑止）
- **オフライン・データ保存**:
  - `sw.js`（`CACHE_NAME: hachamecha-sekai-v5`、Network-First＋オフライン即キャッシュ、`updateViaCache: 'none'` でPWA更新を確実反映、`http:`/`https:`のみ安全登録）
  - `IndexedDB`（`hachamecha_sekai_db`）＋ `localStorage`（`hachamecha_sekai_save_v1`）二重保存＋JSON書き出し/復元
- **将来アプリ化**: `capacitor.config.json`（`webDir: "."`, `scrollEnabled: false`）同梱済み
- **公開方法**:
  - **GitHub Pages**: `.github/workflows/deploy-pages.yml` 同梱（`main` push で自動公開）
  - **Cloudflare Pages**: リポジトリ連携またはフォルダのドラッグ＆ドロップのみで無料・帯域無制限・商用可公開

## 3. 実装済みゲーム仕様一覧

### 3.1 コア独自性・世界観
- **世界観混在**: 和風・スチームパンク・サイバー・深海・メルヘン重工業・神話学園グルメ・ネオン終着駅が交差する世界
- **世界法則（カオスルール）10種**: ステージごとに混線する環境ルール（`js/data/rules.js`）
- **世界共鳴シナジー15種 ＋ 共鳴チェイン**: 主力4人＋支援リンク4人の属性＆種族（**2種族持ちは両方同時カウント**）から自動発動。共鳴ゲージ100%で単独割り込み連携必殺が炸裂

### 3.2 属性・種族・ロール・厳密固定ソート
- **属性（6種）**: 炎(🔥) → 水(💧) → 風(🌪️) → 光(✨) → 闇(🌙) → 無(⚪)
  - 相性: 炎>風>水>炎（有利1.35倍 / 不利0.78倍）、光↔闇（相互1.30倍）、無（等倍安定）
- **種族（7種・2種族持ち対応）**: 人間 → 竜 → 神 → 魔物 → 妖精 → 獣 → 機械
- **ロール（4種）**: タンク(🛡️) → ディーラー(⚔️) → サポーター(🎺) → ヒーラー(💚)
- **固定並び順（`Hacha.util.compareRosterEntities`）**:
  1. 属性順（炎水風光闇無）
  2. 主種族順（人間・竜・神・魔物・妖精・獣・機械）
  3. 副種族順（単一種族 `-1` → 人間 `0` … 機械 `6`）
  4. ロール順（タンク・ディーラー・サポーター・ヒーラー）
  5. 読み仮名（`kana`）による五十音順

### 3.3 収録データボリューム
- **キャラクター24体**（全6属性×4ロール網羅・初期所持6体＋スカウト18体）：全員純カタカナRPG名統一（カグラ/イグニス/ヒノエ/フレア/セイリュウ/シオン/ミズチ/ノア/ライガ/ハヤテ/シルフ/セレス/ソラリス/ルミナ/アリア/ヒカリ/クロガネ/ヨゾラ/ノクス/ツクヨミ/ゼクス/レオン/クロノ/マシロ）。技3種（うち8体は技2＋固有パッシブ）、全技に対象範囲バッジ、固有紹介文は**図鑑画面のみ表示**
- **敵36種**（エリア通常20・エリアボス5・乱入専用6・異界レイドボス5）：全員に固有技と紹介文（図鑑のみ表示）
- **装備42種**（武器14・防具14・装飾14）：品質1〜100%（100%＝**極品質**・1.52倍・虹金オーラアニメーション＆自動ロック）、固有紹介文は図鑑のみ表示（装備画面は5列比較差分表示）
- **ロール別アビリティ100種**（4ロール × 5段階 × 5択）：ロール結晶＋資金で段階解放、選択は無料自由切替
- **PvEコンテンツ5種**:
  1. はちゃめちゃ大陸（5エリア × 10ステージ ＝ 50ステージ、5WAVE、**通常WAVEのみ厳密0.3%で乱入発生**）
  2. 混沌の異界塔（エンドレス階層・階層別世界法則・5階ごとレイド級ボス・乱入なし）
  3. 異界レイド討伐（5種の高難度レイドボス・乱入なし）
  4. 界域の試練（属性/種族出撃縛り6種・乱入なし）
  5. 異界闘技場（完全ソロPvE・ブロンズ〜レジェンド全6階級の4vs4 NPC模擬戦3回戦トーナメント・自動周回可・乱入なし）

### 3.4 メインタブ構成（6タブ横並び）＆UI構造
- **下部メインナビ6タブ**: `🗺️出撃` / `⚔️編成` / `🎒装備` / `🧭派遣` / `📖図鑑` / `⚙️設定`
- **スクロールバー非表示リスト**: 仲間切替帯（編成・装備）は横スクロール＋選択キャラ自動可視化＆タブ間連動、各種一覧（編成・装備・派遣・図鑑・レイド/試練/闘技場）は縦スクロール＋タップ後位置保持
- **図鑑統一レイアウト**: 4タブ（キャラ/敵/装備/アビ）すべてで紹介文を最下部（`flavor-box`）へ統一。キャラ図鑑の加入条件は上部へ配置
- **装備画面＆設定画面の責務分離**: 装備画面の自動売却設定タブを廃止（出撃・設定画面で基準切替、装備画面は一括売却ボタンのみ）。設定画面は独立タブで戦績・効果音・戦闘速度・初入手装備保護・自動売却基準・セーブ入出力・初期化を集約

### 3.5 戦闘システム仕様
- 4人編成（＋支援リンク4枠）、完全フルオート、1x/2x/3x速度切替（テンポ最適化済み）
- 乱入は**大陸の通常WAVEのみ厳密0.3%判定**（1WAVE1回抽選・撃破時は激レア豪華報酬）
- 行動順タイムライン（4体均等表示）、厳格1体逐次実行（同時攻撃なし）、**攻撃・共鳴演出中も他ユニットのCTゲージが継続進行**
- **毎フレームぬるぬるゲージ**：CT・HP・HPダメージ残像バー（`.gauge-hp-trail`）・シールド・共鳴ゲージを滑らかに補間描画
- バフ・デバフ・状態異常をユニットカード内固定高帯（最大6枠＋残ターン数）へ表示
- 行動ログは1行固定・上詰め表示＋最新行ハイライト、撤退確認モーダル表示中は戦闘を安全に一時停止
- DPSメーター4指標（与ダメ/被ダメ/与回復/被回復）、自動周回中は1周ごとにリセットせず累積
- 無限自動周回＆終了予約（`🛑 周回終了` → `⏳ 戦闘後終了`：進行中の戦闘完了後に**周回専用リザルト**へ遷移、待機中なら次周へ進まず即確定、通常戦闘は**通常リザルト**へ遷移）
- ゼロファイル Web Audio API 合成SE（ミュート切替付）
