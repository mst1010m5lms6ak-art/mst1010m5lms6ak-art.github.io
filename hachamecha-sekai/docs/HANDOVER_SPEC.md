## 1. プロジェクト概要・技術アーキテクチャ
- **タイトル**: はちゃめちゃ世界
- **プロジェクトルート**: `C:\Users\ABC\.gemini\antigravity\scratch\hachamecha-world`
- **公開・動作方針**:
  - **ビルド不要（`dist` なし）** の通常 `index.html` 構成。
  - **Pure Vanilla HTML5 / CSS3 / JavaScript（クラシック `<script defer>` 分割＋単一名前空間 `window.HW`）**、外部ライブラリ依存ゼロ。
  - PCでの `index.html` 直接ダブルクリック（`file://`）・GitHub Pages（`main` ルート直配信または `.github/workflows/pages.yml`）・Netlify Drop・Cloudflare Pages・オフラインPWA・将来的な Capacitor（`capacitor.config.json` で `"webDir": "."` 設定済）のすべてに対応。
  - **ファイル数上限**: トータル **100ファイル以内** 厳守（現在41ファイル）。
- **PWA・オフライン・キャッシュ規約**:
  - `sw.js` は **Network-First**（オンライン時は必ず最新を取得してキャッシュ自動更新、オフライン時はキャッシュ応答）を採用。
  - ファイル追加・大幅更新時は `sw.js` の `CACHE_NAME` バージョン番号と `ASSETS` 配列も同期更新すること。
  - `js/ui/app.js` は `updateViaCache: 'none'` ＋ `reg.update()` でSW更新を即時反映させる。
- **セーブ＆セキュリティ規約**:
  - `IndexedDB`（メイン）＋ `localStorage`（ミラー）の二重オフライン保存（`js/core/storage.js`）。
  - FNV-1a系多重署名による改ざん検知＋引き継ぎバックアップコード入出力（`js/core/security.js`）。
  - 全動的テキストは `HW.esc()` でHTMLエスケープし、`index.html` に CSP を設定。
- **発熱防止・軽量規約**:
  - バトル画面以外では `requestAnimationFrame` を完全停止。
  - Canvas 2D パーティクル・ポップアップ数に上限を設け、ゲージ更新は `transform: scaleX()` のみで行う。

## 3. iOS Safari / PWA セーフエリア＆親指ゾーン厳守規約
- **iOS PWA上部めり込み対策**:
  - `<meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover">`
  - `apple-mobile-web-app-status-bar-style="black-translucent"` は iOS standalone での座標ズレ原因となるため**意図的に指定しない**（`manifest.json` の `display: standalone` + `theme_color: #090c16` に委譲）。
  - `#app-root` は `position: fixed; inset: 0;`（`100vh`/`100dvh` 依存を排除）、上下に専用スペーサー `#safe-top` / `#safe-bottom` を配置。
  - `js/ui/dom.js` の `setupMobileGuard()` で iOS standalone 時の `env(safe-area-inset-top)=0` 既知バグ補正と、キーボード収納後の `window.scrollTo(0, 0)` リフローを実施。
  - 長押し選択・コンテキストメニュー・ダブルタップズーム・ピンチズームをCSS＆JSで完全無効化。
- **親指ゾーン上下2分割**:
  - 上部 `#top-stage`（非バトル時 38〜43% / バトル時 53〜55%）：閲覧専用。
  - 下部 `#bottom-dock` ＋ `#bottom-nav`：全タップ操作を集約。
  - トースト通知は下部ナビ直上（`bottom: calc(var(--safe-bottom) + 64px)`）に表示し、上部ヘッダー・通貨・WAVEを隠さない。
