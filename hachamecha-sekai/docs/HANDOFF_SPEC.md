## 1. プロジェクト最優先前提 ＆ 技術アーキテクチャ

- **タイトル**: `はちゃめちゃ世界`
- **基本要件**:
  - ビルド不要（No-Build）構成。ルート直下の `index.html` を直接開いても、GitHub Pages（ブランチ直配信／GitHub Actions）や Cloudflare Pages / Netlify へそのまま上げても即動作する。
  - プロジェクト総ファイル数は **100ファイル以内** を厳守（現在36ファイル）。
  - **iOS Safari（ホーム画面追加PWA）での快適動作・セーフエリア完全対応を最優先**。
  - 将来の **Capacitor による iOS アプリ化** 前提（`capacitor.config.json` は `webDir: "www"`、`npm run cap:prepare` / `scripts/sync-capacitor.mjs` でルートWeb資産を `www/` へ安全複製し `ios/` 循環衝突を回避）。
- **技術構成**:
  - Vanilla HTML / CSS / JavaScript（クラシック `<script defer>` 分割、`window.HS` 名前空間。`type="module"` を使わないことでローカル `file://` 直開き時のCORSエラーを回避）。
  - 描画：軽量DOM ＋ GPU合成CSSアニメーション（`transform` / `opacity`）＋ `requestAnimationFrame`（省エネ暗転モード無しで発熱ゼロ）。
  - オフライン・PWA：`manifest.webmanifest`（`standalone`, `portrait`）＋ `sw.js`（Cache-First静的資産キャッシュ、`file://` 時は安全スキップ）＋ 生成PNGアイコン3種（`icons/icon-180.png`, `192`, `512`）。
  - セーブ＆セキュリティ：IndexedDB（メイン）＋ `localStorage`（ミラー二重保存）＋ FNV-1aチェックサム整合性検証 ＋ `HS1:` バックアップコード入出力。DOM生成は `HS.DOM.el`（`textContent` 専用・`innerHTML` 禁止）＋ 厳格CSPメタタグ。

## 2. 絶対禁止事項（撲滅リスト — 絶対に再導入しないこと）

1. **ガチャ禁止**（キャラ解放は初期・エリア制覇・世界貨交換・異界塔100F踏破のみ）。
2. **デイリー・ウィークリー・マンスリー・スタミナ制禁止**。
3. **PvP禁止**（完全ソロPvE）。
4. **オプション系ハクスラ（ランダムサブステ厳選）禁止**（装備は品質1〜100%＋セット効果のみ）。
5. **キャライラスト禁止（`<svg>` 含む一切のSVG要素禁止）**。アイコンは標準記号・絵文字とCSS幾何学装飾のみ。
6. **キャラのレベルシステム禁止**（育成はロール別アビリティ・技熟練・刻印覚醒・装備品質/セット・控え共鳴）。※異界レイドの難易度段階のみレベル選択式。
7. **装備強化システム（+1/+2など）禁止**。
8. **メタ発言・設定そのまま説明文の禁止**（「○○は1行固定」「戦闘はフルオートです」「図鑑ボーナスはありません」「上半分では操作できません」等の文言をUIに書かない）。
9. **不要な微細スクロール禁止**（固定項目画面はビューポート内に完全収容。動的リストのみ `.scroll-zone` 内でスクロール）。
10. **枠とスクロールバーの被り禁止**（`.scroll-zone` の右余白と細身トラックを維持）。
11. **要素増減によるレイアウトズレ・見切れ禁止**（戦闘アリーナ2×2固定高、状態異常枠固定高、ログ独立ブロック流）。
12. **名前の「…」省略（`text-overflow: ellipsis`）禁止**（かつ不自然な極短略称も禁止）。
13. **PWA起動時の上ズレ・セーフエリアめり込み禁止**（`viewport-fit=cover` ＋ 背景層と `.app-shell` の分離 ＋ `js/core/dom.js` の `syncSafeArea()` による iOS standalone コールドスタート0px補正を維持）。
14. **画面上半分（Y < 50%）での操作UI配置禁止**（全画面・全サブタブ・全ボトムシートにおいて操作ボタンは下半分に集約。`.upper-display` は表示専用）。
15. **戦闘中の他画面遷移禁止**（戦闘中は `#bottom-nav` を `hidden-in-battle` で完全非表示）。
16. **同時攻撃禁止**（`BattleSession` の `readyQueue` ＋ `actionLockTimer` により1体ずつ逐次実行。攻撃演出中も行動ゲージは連続進行）。
17. **異界塔・異界レイド・制約異界での自動周回禁止**（無限自動周回は通常異界のみ）。
18. **図鑑ボーナス禁止**（図鑑4種は完全観賞用）。

## 3. 実装済みコア仕様サマリー

- **属性（6種）＆並び順**: `炎 → 水 → 風 → 光 → 闇 → 無`（炎＞風＞水＞炎の三すくみ：有利1.30倍/不利0.80倍、光↔闇：相互1.25倍、無：等倍安定）。
- **種族（7種＋2種族持ち）＆並び順**: `人間 → 竜 → 神 → 魔物 → 妖精 → 獣 → 機械`。2種族は `単種族 → 複合種族` 順（例：`人間 → 人間・竜 → 人間・魔物`）。
- **ロール（4種）＆並び順**: `タンク → ディーラー → サポーター → ヒーラー`。
- **規定ソート順**: 属性 → 種族（2種族規約）→ ロール → 五十音順（`kana` 基準）。`HS.CONST.compareUnits` で全画面統一。
- **キャラクター（33体）**: 初期4体 ＋ 通常エリア1〜6制覇6体 ＋ 世界貨交換21体 ＋ 異界塔Ⅰ/Ⅱ 100F踏破限定2体。基本3技（強さ1＜2＜3）または2技＋固有パッシブ。全技に単体/範囲/全体の対象区分を表示。固有紹介文付き。
- **やり込み育成（レベル無し）**:
  - ロール別アビリティ：4ロール×5段階×各5択＝100種。段階解放後は無料切替可能。
  - 技熟練マスタリー：戦闘参加＆鍛錬でランクⅠ〜Ⅴ（威力上昇・Ⅴで高CT技CT-1）。
  - キャラ固有刻印覚醒：3段階。
- **余剰キャラ活用**:
  - 控え共鳴リンク（前衛4人に各1人リンク：固有共鳴パッシブ＋基礎ステ一部還元＋シナジーカウント貢献）。
  - 異界遠征隊（最大3部隊×最大4人派遣：オフライン実時間経過＋通常勝利ごとの時間短縮加速）。
- **PvE 4モード**:
  - 通常異界（6エリア×10話・5WAVE・通常敵1〜4体ランダム・非ボスWAVEで乱入敵出現・無限自動周回可）。
  - 異界塔（Ⅰ・Ⅱ各100F・強め・各階1度きり報酬・各100F踏破で限定キャラ・自動周回不可）。
  - 異界レイド（6属性別・Lv.1〜10選択式・高HP・レイド限定装備6セットドロップ・自動周回不可）。
  - 制約異界（8種の属性/種族/ロール縛り・自動周回不可）。
- **戦闘＆リザルト**:
  - 1x/2x/3x速切替、行動順バー（3枠フルネーム非見切れ）、ぬるぬる `scaleX` ゲージ、技CT＆バフ/デバフ/状態異常常時可視化、戦況ログ（折り返しズレ対策済）、DPSメーター（与ダメ/被ダメ/与回復/被回復、自動周回時は累積）。
  - 通常リザルトと自動周回リザルトは完全別画面。周回終了予約時は進行中の戦闘完了後に自動周回リザルトへ遷移。
- **装備＆品質＆自動売却**:
  - 4部位（武器/防具/装飾/核）、14セット56種（レイド限定6セット含む）。
  - 品質1〜100%（×1.00〜×1.55）。最大品質100%は虹枠（`.quality-perfect`）＋`✦極100%`徽章で一目判別、自動売却から自動保護。

## 4. 開発の進め方ルール（次回セッション共通）

1. 作業開始前に必ず `docs/HANDOFF_SPEC.md` と `docs/CODE_MAP.md` を確認し、必要なファイル・該当行範囲だけを読む（全ファイル総読みしない）。
2. 新規ファイル追加時は `sw.js` の `CORE_ASSETS` と `index.html` の `<script defer>` 読み込み順を更新し、総ファイル数100以内を維持する。
3. 実装後は必ず構文チェック・禁止事項チェック（`<svg>` / `innerHTML` / メタ文言ゼロ）を行い、ローカルサーバー＋ブラウザ（iPhone縦画面 `375x812` / `390x844`）で全画面テストプレイを実施する。
4. テストで発見したバグ・上半分操作箇所（`Y < 50%`）・見切れ・ズレを改修し、再度テストプレイで0件を確認する。
5. 最終変更に合わせて `docs/HANDOFF_SPEC.md`・`docs/CODE_MAP.md`・`docs/DATA_NAMES_LIST.md` を最新化する。
