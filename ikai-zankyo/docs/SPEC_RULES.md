## 1. プロジェクト概要・実行環境
- **タイトル**：異界残響
- **配置先**：`c:\Users\ABC\AppData\Local\Temp\newapp1\ikai-zankyo\`
- **動作構成**：**ビルド不要の素の HTML / CSS / JavaScript**（`dist/` なし。プロジェクトルート直下の `index.html` がそのまま本番）
  - PCでの直接閲覧（`file://` およびローカル配信）
  - **iPhone 14 を含むホームボタン無し全iPhoneの Safari PWA（ホーム画面に追加・スタンドアロン全画面・縦画面固定）**
    - `#device-stage` を `position: fixed; inset: 0` で物理画面100%へ完全固定し、`env(safe-area-inset-top/bottom)` 直接評価＋iOSスタンドアロンcold-start保護フォールバックにより上ズレ・下部余白を完全防止
  - 将来的な **iOSアプリ化（Capacitor 等で `webDir` にそのまま適用可能）**
  - **完全オフライン対応**（外部CDN・外部フォント・外部通信ゼロ、Service Worker Network-First＋オフラインキャッシュ `ikai-zankyo-v5`）

- **世界観と雰囲気**：多彩な10異界（遺跡・蒸気鍛炉・夜桜古都・深海神殿・時計塔・世界樹森域・太陽砂都・極光凍城・電脳尖塔・終焉星海）ごとに背景色調・UIアクセントがダイナミックに切替

## 2. 必須ルール（絶対遵守）
1. **SafeArea配慮**：上部・下部に独立した SafeArea 帯（`env(safe-area-inset-top/bottom)` 直接評価）と明確な発光境界線（`.safe-boundary`）を設け、ゲーム画面とのズレや見切れを一切起こさない。
2. **画面上半分で一切操作しないUI**：ゲーム領域を上下 `50% : 50%` に完全固定分割。上半分（`#upper-display`）は `pointer-events: none` の完全閲覧専用とし、すべてのボタン・タブ・リスト・入力・切替・召喚演出スキップ操作を下半分（`#lower-control`）に集約する。
3. **視認性抜群・利便性抜群・統一感・凝った・分かりやすいUI**：情報強弱・等幅数値・アイコン体系を統一し、画面に不自然な空白や見切れ・分かりにくい略語（`初回石`、`与 被 癒 受`等）を作らない。
4. **数字や要素が増えてもずれないUI**：固定グリッド、等幅数値（`tabular-nums`）、桁圧縮フォーマット（万/億）、固定高さカード＆固定高さ上段行（`.stage-card-head`）により数値増減・`済`/`強敵`バッジ有無で1pxもズレさせない。
5. **10異界 × 各10ステージ・5連戦**：メイン異界探索は10異界 × 10ステージ × 5連戦（計100ステージ）。
6. **強敵（ボス）＆乱入の明快な単独出現**：
   - ステージ5・10の最終波に**エリアボスが単独出現**（大型赤金プレート・王冠バッジ・突入フラッシュバナー・専用SE）。
   - 通常波で確率出現する**乱入枠の敵も単独出現**（大型紫金プレート・警告バッジ・突入フラッシュバナー・専用SE・豪華報酬）。
7. **ノンストップ・フルオートバトル（速度ATBタイムライン制＋クールタイム方式）**：
   - 倍速切替（`×1 / ×2 / ×3`）。
   - **攻撃演出中も全生存ユニットのATBゲージと行動順が硬直せず進み続ける**ノンストップ進行。
   - 固定3段内部完結ユニットカード（めり込み0px・境界見切れ0px）＋ **攻撃者→対象のSVG光跡ライン＆着弾リング** ＋ **中央アタックレーン（`誰 ▶ 技名 [範囲] ▶ 対象`）** で戦況を一目で把握可能。
8. **味方編成とロール**：4人編成。ロールは4種（タンク・ディーラー・サポーター・ヒーラー）。通常敵は1〜4体。キャラ名はすべて肩書きなしの自然なパーソナルネーム（例：`ロイ`、`レン`、`リナ`等）。
9. **技仕様**：
   - 味方技は3枠（強さ `1 < 2 < 3`、一部キャラは「技2つ＋常時パッシブ」）。
   - 敵にも技が2つ（通常技＋強技CT付き・強技構え予告表示）。
   - すべての技と中央レーンに **単体 / 範囲2体 / 範囲3体 / 全体 / 常時** が一目で分かる色分けバッジを表示。
10. **レアリティ・属性・育成・シナジー・装備・召喚**：
    - レアリティ5段階：`N / R / SR / SSR / UR`。
    - 属性6種：`炎 / 水 / 風 / 光 / 闇 / 無`（`炎＞風＞水＞炎`、`光⇔闇` 相互有利、`無` は相性なし）。
    - Lvなしのやり込み育成3本柱：①キャラ別「共鳴盤」（6ノード自由順解放・共鳴結晶消費） ②「覚醒」（0〜5段階・魂晶消費・覚醒2/4で自由枠拡張） ③「自由アビリティ装着」（30種）。
    - 3軸編成シナジー（属性・ロール・出身異界）が重複発動。
    - 装備4枠（武器・防具・装飾・紋章）・20シリーズ（通常14＋異界討伐限定6）・**2部位＆4部位セット効果**・品質5段階（`標準 < 上質 < 精巧 < 逸品 < 至宝`、高品質ほど低確率で基礎値＆セット効果倍率上昇）。装着画面では上昇パラメータ名＋数値＋現在装着品との差分を明示。
    - 召喚画面：上半分に二重回転幾何学魔法陣ゲート常設、召喚時は光柱収束→最高レア色フラッシュ→カード連続公開演出（下半分で即時スキップ可）。通常召喚にもUR枠（3%）を配置。
11. **必須ソート順**：
    - **キャラ**（編成・育成・共鳴・図鑑）：`レアリティ順（UR→SSR→SR→R→N） → 属性順（炎→水→風→光→闇→無） → ロール順（タンク→ディーラー→サポーター→ヒーラー） → 五十音順（kana）`
    - **敵**（図鑑）：`属性順（炎→水→風→光→闇→無） → 種別順（通常敵→乱入→エリアボス→異界討伐ボス） → 五十音順（kana）`
    - **装備**（図鑑）：部位名リスト表示・`武器 → 防具 → 装飾 → 紋章` 順（通常→限定・階級順）
    - **異界討伐**：属性順（`炎イグニス → 水レヴィア → 風ヴァルキリア → 光クロノア → 闇クチナワ → 無オメガ`）
12. **自動周回＆リザルト仕様**：
    - 回数指定なし。敗北しても自動リトライ継続（終了は手動の停止予約）。
    - 自動周回終了（停止予約）時は**その周が終了してから**、全周回分の**トータルリザルト**（勝敗数・乱入撃破数・獲得通貨/素材/鍵/覇王の印/加入仲間・1行統一の獲得装備詳細・自動売却集計・累計一括DPSメーター・MVP）を表示。
13. **一括売却・自動売却・金貨還元**：品質指定で自動売却（出撃画面からの1タップ切替にも対応）／一括売却が可能（装着中およびロック保護済み装備は絶対売却しない）。金貨は共鳴結晶・残響石へ1回/5回まとめて還元可能。
14. **余ったキャラ活用コンテンツ（遠征・派遣なし）**：
    - ① **共鳴**（控えキャラを出撃キャラへ共鳴させて能力加算＆特性付与、覚醒・共鳴盤育成度で強化、時間待ちなし）
    - ② **総力連戦「残響回廊」**（最大3パーティ12人・重複不可の連続ボス戦、おまかせ3部隊自動編成あり）
    - ③ **覚醒上限超過の自動変換**（魂晶＆共鳴結晶へ即時変換）
15. **豊富な常設PvEコンテンツ5種**：
    - ① **異界探索**（10異界×10ステージ×5連戦：通常装備14シリーズ獲得）
    - ② **異界討伐**（属性順6単独巨大ボス×3難度：通常装備ドロップなし、限定装備素材6種＆限定キャラ鍵6種＆**討伐ボスUR6体解放用の覇王の印**を獲得）
    - ③ **総力連戦**（4コース×3連戦：最大3部隊12人制覇）
    - ④ **深淵の塔**（**100階層踏破**・5層ごと単独ボス・10F単位横スクロール帯・**25F/50F/75F/100Fに塔限定キャラ4体**＋節目限定アビリティ4種）
    - ⑤ **試練の狭間**（8種の属性/ロール/低レア/人数条件チャレンジ・限定アビリティ8種）
16. **一目で全部見れるDPSメーター**：戦闘中下半分に4人全員の **与ダメ・被ダメ・回復量・被回復** の4項目を同時リアルタイム表示（切替不要・ぬるぬるバー）。
17. **快適なスクロール＆位置保持**：縦リスト（`.scroll-list`）および選択バー（`.h-scroll-row`：エリア1〜10、深淵の塔10F帯、育成/装備のキャラ切替、図鑑フィルタ）はスクロールバー非表示で滑らかに操作可能。再描画時は `data-scroll-key` ごとに `scrollTop` / `scrollLeft` を完全復元し、タップで先頭へ戻らない。
18. **詳細な図鑑＆紹介文ルール**：サブタブは `キャラ / 敵 / 装備 / 設定`。キャラ52体・敵66種（基礎4ステ＋出現場所・撃破数削除）・装備80部位（5品質パラメータ＋部位別紹介文）の詳細図鑑。**キャラ・敵・装備の紹介文（`lore` / `partLores`）は図鑑画面にのみ表示**し、他画面へ出さない。
19. **万全のセキュリティ対策**：内部状態のグローバル非露出（IIFE隠蔽）、ストリーム暗号化＋SHA-256 HMAC改ざん検知、二重バックアップ自動復旧、スキーマ＆数値範囲検証、CSP設定＆HTMLエスケープ（XSS完全防止）、暗号化署名付き引き継ぎコード。

## 3. 禁止ルール（絶対厳守・1つでも抵触したら即改修）
- ❌ 変な名前、違和感のある名前、肩書き付きキャラ名
- ❌ アクション操作（完全フルオートのみ）
- ❌ オプション厳選型ハクスラ（ランダムサブOPは絶対禁止）
- ❌ 陣形（前後列・配置ボーナス・並び順による有利不利は禁止。範囲攻撃は対象＋複数体指定）
- ❌ デイリー、ウィークリー、マンスリー、実績
- ❌ 遠征や派遣のような時間待ち放置コンテンツ
- ❌ キャライラスト（SVGイラスト含む。SVGは汎用UI記号・属性マーク・ロール記号・装備記号・幾何学魔法陣/攻撃軌跡のみ）
- ❌ 画像生成によるアイコン
- ❌ PvPコンテンツ、ランキング
- ❌ **キャラLv、装備Lv**（文字表記も含め一切禁止）
- ❌ 戦闘中の撤退ボタン・撤退機能
- ❌ 名前が「・・・」で省略されるUI（`text-overflow: ellipsis` や `…` 省略禁止）
- ❌ 開発内容やシステム仕様を説明するようなメタ発言をゲーム内に記載
- ❌ タップの感度が弱い、発熱させるような重さ、攻撃ごとの硬直など悪いテンポ
- ❌ スクロールバーの表示、リスト・選択帯（`.scroll-list` / `.h-scroll-row`）以外の冗長な画面スクロール（リザルト画面等が縦に長々伸びることの禁止）
