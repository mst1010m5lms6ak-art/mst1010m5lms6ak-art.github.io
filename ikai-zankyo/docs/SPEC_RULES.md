## 1. プロジェクト概要・実行環境
- **タイトル**：異界残響
- **配置先**：`c:\Users\ABC\AppData\Local\Temp\newapp1\ikai-zankyo\`
- **動作構成**：**ビルド不要の素の HTML / CSS / JavaScript**（`dist/` なし。プロジェクトルート直下の `index.html` がそのまま本番）
  - PCでの直接閲覧（`file://` およびローカル配信）
  - **iPhone 14 を含むホームボタン無し全iPhoneの Safari PWA（ホーム画面に追加・スタンドアロン全画面・縦画面固定）**
    - `apple-mobile-web-app-status-bar-style: black` ＋ `viewport-fit=cover` ＋ `#device-stage` の `--app-vh` 実測二重ガード（`syncIosSafeAreaGuard`）により、iOS PWA特有のステータスバー起因の下部謎余白＆上部暗転見切れを完全防止
  - 将来的な **iOSアプリ化（Capacitor 等で `webDir` にそのまま適用可能）**
  - **完全オフライン対応**（外部CDN・外部フォント・外部通信ゼロ、Service Worker Network-First＋オフラインキャッシュ `ikai-zankyo-v6`）
- **ジャンル**：買い切り型2D戦略RPG（スタミナ制・課金・時限イベント一切なし）
- **世界観と雰囲気**：多彩な10異界（遺跡・蒸気鍛炉・夜桜古都・深海神殿・時計塔・世界樹森域・太陽砂都・極光凍城・電脳尖塔・終焉星海）ごとに背景色調・UIアクセントがダイナミックに切替
- **配色・質感・フォント**：ダークラグジュアリー × 鋭角タクティカル × クリスタル・エレメンタル発光基調。見出しはオフライン最適明朝（`--font-display`）、本文・UI・数値は高判読性ゴシック（`--font-sans`）＋等幅数値（`tabular-nums`）＋軽量Web AudioシンセSE（ON/OFF切替可）

## 2. 必須ルール（絶対遵守）
1. **SafeArea配慮**：上部・下部に独立した SafeArea 帯（`env(safe-area-inset-top/bottom)` 直接評価＋実測保護ガード）と明確な発光境界線（`.safe-boundary`）を設け、ゲーム画面とのズレ・謎の下部余白・上部見切れを一切起こさない。
2. **画面上半分で一切操作しないUI**：ゲーム領域を上下 `50% : 50%` に完全固定分割。上半分（`#upper-display`）は `pointer-events: none` の完全閲覧専用とし、すべてのボタン・タブ・リスト・入力・切替・召喚演出スキップ操作を下半分（`#lower-control`）に集約する。トースト通知は上半分最下部（`bottom: 8px`）へ配置し、ヘッダー・ロール・通貨へ一切干渉させない。
3. **視認性抜群・利便性抜群・統一感・凝った・分かりやすいUI**：情報強弱・等幅数値・アイコン体系を統一し、画面に不自然な空白や見切れ・分かりにくい略語（`初回石`、`与 被 癒 受`等）を作らない。
4. **数字や要素が増えてもずれないUI**：固定グリッド、等幅数値（`tabular-nums`）、桁圧縮フォーマット（万/億・最大6〜7文字収容）、固定高さカード＆固定高さ上段行（`.stage-card-head`）により数値増減・`済`/`強敵`バッジ有無で1pxもズレさせず、リザルト数値の枠貫通を起こさない。
5. **10異界 × 各10ステージ・5連戦**：メイン異界探索は10異界 × 10ステージ × 5連戦（計100ステージ）。ステージ選択画面の上半分では**乱入敵の表示を出さず**、**全ステージ（ステージ5・10含む）で異界情景を常時記載**し、ボスは「出現敵」欄へ赤金枠の強敵チップとして記載、最下部に現在の出撃パーティ4人ミニ帯を表示する。
6. **強敵（ボス）＆乱入の明快な単独出現**：
   - ステージ5・10の最終波に**エリアボスが単独出現**（引き締まった適正高さの赤金プレート・王冠バッジ・突入フラッシュバナー・専用SE）。
   - 通常波で確率出現する**乱入枠の敵も単独出現**（引き締まった適正高さの紫金プレート・警告バッジ・突入フラッシュバナー・専用SE・豪華報酬）。
   - 敵2体時・単独ボス時・単独乱入時は、カードを縦に余剰伸ばしせず中央寄せの適正高さで表示する。
7. **ノンストップ・フルオートバトル（速度ATB＋行動順キュー＋低発熱設計）**：
   - 倍速切替（`×1 / ×2 / ×3`）。
   - **攻撃演出中も全生存ユニットのATBゲージと行動順が硬直せず進み続ける**ノンストップ進行。
   - **行動順キュー**：敵味方混合で到達残り時間（速度反映）が早い順に最大5体を独立スロットで並列表示（先頭金色強調・名前被り完全0px）。
   - **ユニットカード**：HP数値テキストは非表示とし、1行目は属性・名前・ロール（敵ボス/乱入は強敵/乱入バッジ）で衝突ゼロ、2行目は視認性の高いHP残像バー＋ATBバー、3行目はバフ/デバフ＆技CT。フローティングポップはカード中央ゲージ帯に収め上下非干渉。
   - **攻撃軌跡＆中央レーン**：攻撃者→対象のSVG光跡ライン＆着弾リング ＋ 中央アタックレーン（`誰 ▶ 技名 [範囲] ▶ 対象`）。
   - **低発熱・省電力エンジン**：戦闘描画の30fpsスロットリング、上/下半分のDOMマウント分離（波切替時に下半分ボタンを再生成せずタップ抜け完全防止）、全DOMノード＆座標キャッシュ、変化時のみの差分更新、`transform: scaleX()` によるGPU合成バー更新、軽量速度取得（毎フレーム `getSnapshot()` 廃止）。
8. **味方編成とロール**：4人編成。ロールは4種（タンク・ディーラー・サポーター・ヒーラー）。通常敵は1〜4体。キャラ名はすべて肩書きなしの自然なパーソナルネーム（例：`ロイ`、`レン`、`リナ`等）。
9. **技仕様＆倍率表記**：
   - 味方技は3枠（強さ `1 < 2 < 3`、一部キャラは「技2つ＋常時パッシブ」）。
   - 敵にも技が2つ（通常技＋強技CT付き・強技構え予告表示）。
   - すべての技プレビューに **倍率表記（`倍率XXX%` / `回復XXX%`）・CT・対象範囲バッジ（単体 / 範囲2体 / 範囲3体 / 全体 / 常時）** を統一表示。
10. **下部5タブ構成＆統合「キャラ」タブ・独立「設定」タブ**：
    - メインナビは5タブ：**`出撃 / キャラ / 召喚 / 図鑑 / 設定`**。
    - **統合「キャラ」タブ**：編成（主力4人・総力連戦3部隊）・刻印・覚醒・アビ・共鳴・装備（装着・売却/自動・限定製作・金貨還元）のすべてを1タブへ統合し、選択キャラ同期＆横スクロールキャラ帯でシームレスに操作可能。
    - **独立「設定」タブ**：上半分に記録と戦績ハイライト、下半分にSE・戦闘速度（×1/×2/×3）・2行折り返し引き継ぎコード（スクロールバー非表示）・安全分離した初期化操作を配置。
11. **レアリティ・属性・育成（刻印12種・手動覚醒）・シナジー・装備・召喚**：
    - レアリティ5段階：`N / R / SR / SSR / UR`。
    - 属性6種：`炎 / 水 / 風 / 光 / 闇 / 無`（`炎＞風＞水＞炎`、`光⇔闇` 相互有利、`無` は相性なし）。
    - Lvなしのやり込み育成3本柱：①キャラ別 **「刻印」12種**（自由順全解放・**結晶**消費） ② **「覚醒」**（0〜5段階・魂晶による手動覚醒に一本化・覚醒2/4で自由枠拡張・1〜5段階ロードマップ表示） ③ **「自由アビリティ装着」**（30種）。
    - **重複入手は覚醒させない**：召喚・限定解放・覇王降臨・塔報酬を問わず、所持済みキャラの重複入手はすべて覚醒させず即座に **魂晶＋結晶** へ自動変換する。
    - 3軸編成シナジー（属性・ロール・出身異界）が重複発動。
    - 装備4枠（武器・防具・装飾・紋章）・20シリーズ（通常14＋異界討伐限定6）・**2部位＆4部位セット効果**・品質5段階（`標準 < 上質 < 精巧 < 逸品 < 至宝`、高品質ほど低確率で基礎値＆セット効果倍率上昇）。装着画面では上昇パラメータ名＋数値＋現在装着品との差分＋総合5ステを明示。
    - 召喚画面：上半分に二重回転幾何学魔法陣ゲート常設、召喚時は光柱収束→最高レア色フラッシュ→カード連続公開演出（下半分で即時スキップ可）。**タブ切り替え・サブタブ切り替え時は必ず召喚陣へ自動復帰**。通常召喚UR枠（3%）は全6属性1体ずつ計6体（タップで図鑑詳細へ直通）。
12. **必須ソート順**：
    - **キャラ**（編成・育成・共鳴・図鑑）：`レアリティ順（UR→SSR→SR→R→N） → 属性順（炎→水→風→光→闇→無） → ロール順（タンク→ディーラー→サポーター→ヒーラー） → 五十音順（kana）`
    - **敵**（図鑑）：`属性順（炎→水→風→光→闇→無） → 種別順（通常敵→乱入→エリアボス→異界討伐ボス） → 五十音順（kana）`
    - **装備**（図鑑）：部位名リスト表示・`武器 → 防具 → 装飾 → 紋章` 順（通常→限定・階級順）
    - **異界討伐**：属性順（`炎イグニス → 水レヴィア → 風ヴァルキリア → 光クロノア → 闇クチナワ → 無オメガ`）
13. **自動周回・至宝ドロップ通知＆リザルト仕様**：
    - 回数指定なし。敗北しても自動リトライ継続（終了は手動の停止予約）。
    - 自動周回中は、下半分サマリー帯に **至宝獲得数＆最新至宝名** を常時表示し、至宝獲得瞬間に金色フラッシュバナー＆専用SEで即通知。
    - 自動周回終了（停止予約）時は**その周が終了してから**、全周回分の**トータルリザルト**（枠貫通ゼロの8マス集計＋平均DPS/売却換金/至宝数帯＋獲得装備＆品質別内訳＋累計DPSメーター・MVP）を表示。
14. **一括売却・自動売却・金貨還元**：品質指定で自動売却（出撃画面からの1タップ切替にも対応）／一括売却が可能（装着中およびロック保護済み装備は絶対売却しない）。金貨は結晶・残響石へ1回/5回まとめて還元可能。
15. **余ったキャラ活用コンテンツ（遠征・派遣なし）**：
    - ① **共鳴**（控えキャラを出撃キャラへ共鳴させて能力加算＆特性付与、覚醒・刻印解放数で強化、時間待ちなし）
    - ② **総力連戦「残響回廊」**（最大3パーティ12人・重複不可の連続ボス戦、おまかせ3部隊自動編成あり）
    - ③ **重複入手の即時変換**（所持済みキャラ再獲得時は覚醒せず即座に魂晶＆結晶へ変換）
16. **豊富な常設PvEコンテンツ5種**：
    - ① **異界探索**（10異界×10ステージ×5連戦：通常装備14シリーズ獲得）
    - ② **異界討伐**（属性順6単独巨大ボス×3難度：通常装備ドロップなし、限定装備素材6種＆限定キャラ鍵6種＆**討伐ボスUR6体解放用の覇王の印**を獲得）
    - ③ **総力連戦**（4コース×3連戦：最大3部隊12人制覇）
    - ④ **深淵の塔**（**100階層踏破**・5層ごと単独ボス・10F単位横スクロール帯・**25F/50F/75F/100Fに塔限定キャラ4体**＋節目限定アビリティ4種）
    - ⑤ **試練の狭間**（8種の属性/ロール/低レア/人数条件チャレンジ・限定アビリティ8種）
17. **一目で全部見れるリアルタイムDPS＆戦績ボード**：戦闘中下半分にサマリー帯（合計DPS・経過時間・至宝/総与ダメ）＋4人全員の **個別DPS（ヒーラーはHPS優先表示）・貢献%・太めメインバー** ＋ **与ダメ・被ダメ・回復・被回復** の4項目を同時リアルタイム表示（倍速に左右されない戦闘時間基準・切替不要）。
18. **快適なスクロール＆位置保持**：縦リスト（`.scroll-list`）および選択バー（`.h-scroll-row`）はスクロールバー完全非表示で滑らかに操作可能。再描画時は `data-scroll-key` ごとに `scrollTop` / `scrollLeft` を完全復元し、タップで先頭へ戻らない。
19. **詳細な図鑑＆紹介文ルール**：図鑑サブタブは `キャラ / 敵 / 装備` の3種。キャラ56体・敵66種（基礎4ステ＋出現場所・技倍率表示・撃破数削除）・装備80部位（5品質パラメータ＋部位別紹介文）の詳細図鑑。**キャラ・敵・装備の紹介文（`lore` / `partLores`）は図鑑画面にのみ表示**し、他画面へ出さない。
20. **万全のセキュリティ対策**：内部状態のグローバル非露出（IIFE隠蔽）、ストリーム暗号化＋SHA-256 HMAC改ざん検知、二重バックアップ自動復旧、スキーマ＆数値範囲検証、CSP設定＆HTMLエスケープ（XSS完全防止）、暗号化署名付き引き継ぎコード。

## 3. 禁止ルール（絶対厳守・1つでも抵触したら即改修）
- ❌ 変な名前、違和感のある名前、肩書き付きキャラ名
- ❌ アクション操作（完全フルオートのみ）
- ❌ オプション厳選型ハクスラ（ランダムサブOPは絶対禁止）
- ❌ 陣形（前後列・配置ボーナス・並び順による有利不利は禁止。範囲攻撃は対象＋複数体指定）
- ❌ デイリー、ウィークリー、マンスリー、実績
- ❌ 遠征や派遣のような時間待ち放置コンテンツ
- ❌ キャライラスト（SVGイラスト含む。SVGは汎用UI記号・属性マーク・ロール記号・装備記号・幾何学魔法陣/攻撃軌跡のみ）
- ❌ 画像生成によるアイコン
- ❌ PvPコンテンツ、ランキング
- ❌ **キャラLv、装備Lv**（文字表記も含め一切禁止）
- ❌ **キャラ重複による自動覚醒**（重複時は必ず魂晶＋結晶変換、覚醒は魂晶での手動のみ）
- ❌ 戦闘中の撤退ボタン・撤退機能
- ❌ 名前が「・・・」で省略されるUI（`text-overflow: ellipsis` や `…` 省略禁止）
- ❌ 開発内容やシステム仕様を説明するようなメタ発言をゲーム内に記載
- ❌ タップの感度が弱い、発熱させるような重さ、攻撃ごとの硬直など悪いテンポ
- ❌ スクロールバーの表示（`textarea` 等含む）、リスト・選択帯（`.scroll-list` / `.h-scroll-row`）以外の冗長な画面スクロール（リザルト画面等が縦に長々伸びることの禁止）
