> **次回以降の開発・改修時の必読ドキュメント**
> 既存実装を誤って削除・劣化させたり、禁止事項を混入させたりしないため、変更前に本仕様書と `docs/CODE_MAP.md` を必ず確認すること。

## 1. 絶対厳守の禁止事項（実装・混入厳禁）

以下は**いかなる機能追加・改修においても絶対に導入・違反してはならない**。

1. **ガチャ禁止**: ランダム排出ガチャ・有料/無料召喚システムは一切作らない。仲間の加入は「ステージ初回クリア」「無限塔到達」「カオス結晶による確定解放」のみとする。
2. **時間縛りルーティン禁止**: デイリー・ウィークリー・マンスリークエスト、ログインボーナス、スタミナ制、曜日限定ダンジョンは一切作らない。
3. **PvP禁止**: ランキング・対人戦・マルチプレイ・ギルド戦は一切作らない（完全ソロPvE専用）。
4. **キャライラスト禁止**: キャラクター立ち絵・画像スプライトは使用しない。視覚表現はインラインSVG幾何学エンブレム（`Emblem.tsx`）・タイポグラフィ・CSSアニメーション・軽量Canvas 2Dパーティクルのみとする。
5. **ゲーム内メタ発言・設定説明文の撲滅**: ゲーム画面のテキストに、開発・仕様・実装に関するメタ発言（例：「○○は1行固定」「ガチャ無し」「軽量化のため」「親指ゾーン」「テスト用」「実装済み」等）を1文字も表示しない。
6. **微妙なスクロール範囲の生成禁止**: `html / body / #app / .app-shell` および戦闘画面 `.battle-root` は `100dvh` + `overflow: hidden` で完全固定し、ページ全体が数pxだけガタつくスクロールを絶対に発生させない。スクロールは `.scroll-area` を付与した明確な一覧領域のみ許可する。
7. **ずれて見切れるUIの禁止**: 最小幅 `375×667` (iPhone SE) 〜 `393×852` (iPhone 15 Pro) 〜 デスクトップ大画面（最大幅480px中央筐体）のすべてで、文字見切れ・ボタン潰れ・要素重なりを発生させない。
8. **戦闘中の他画面移動禁止**: 戦闘中（`battle !== null`）は他画面（出撃・編成・装備・仲間・設定）へ絶対に遷移させない（パーティ変更による敗北事故防止）。下部ナビ非表示＋`handleSelectTab` ロックの二重ガードを維持する。
9. **戦闘ログの2行折り返し禁止**: `.battle-log-row` は固定高さ `17px` + `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;` を絶対に崩さない。ログ文言は1行に収まる簡潔フォーマットを維持する。
10. **プロジェクト総ファイル数上限（100ファイル以内）**: `node_modules` / `dist` / `.git` を除くプロジェクト内ファイル総数を常に100ファイル以内に保つ（現在 **44ファイル**）。
11. **容量肥大化の禁止**: 演出軽量化設定でごまかすのではなく、バンドル・アセット容量自体を極小に保つ（重いフレームワーク・巨大画像・外部音声ファイルの追加禁止。現在 JS gzip ~50KB / プリキャッシュ総計 ~228KB）。

## 2. プラットフォーム・PWA・セーフエリア要件（破壊禁止）

- **最優先ターゲット**: GitHub Pages（GitHub Actions）経由URL → iOS Safari → 「ホーム画面に追加」したPWAスタンドアロン動作。
- **将来展開**: Capacitor で iOS アプリ化前提（`vite.config.ts` の `base: './'` と `capacitor.config.json` の `webDir: 'dist'` を維持。Service Worker 登録は `!('Capacitor' in window)` で保護）。
- **セーフエリア完全対応**:
  - `index.html`: `viewport-fit=cover`, `maximum-scale=1.0, user-scalable=no`, `apple-mobile-web-app-capable`, `apple-mobile-web-app-status-bar-style=black-translucent`。
  - `src/styles/theme.css`: `--safe-top: max(env(safe-area-inset-top, 0px), 6px)` / `--safe-bottom: calc(env(safe-area-inset-bottom, 0px) + 12px)`（Safari下部シングルタブ誤タップ防止の+12px余裕込み）。
- **iOS誤操作防止**:
  - CSS: `-webkit-user-select: none`, `user-select: none`, `-webkit-touch-callout: none`, `touch-action: manipulation`（D&D要素は `touch-action: none`、テキスト入力欄のみ `font-size: 16px` でズーム防止＆選択許可）。
  - JS (`src/main.tsx`): `contextmenu` / `gesturestart` / 連続 `touchend`(<=280ms) を抑止。
- **オフライン永続セーブ**:
  - `IndexedDB` プライマリ + `localStorage` フォールバック二重保存 + `navigator.storage.persist()` + バックアップコード書き出し/復元。
- **親指ゾーン（Thumb Zone）最適化**:
  - 画面上部（デッドゾーン）は視認専用（リソース、行動順、カオスゲージ、ログ、敵情報）。
  - 操作系（カテゴリ切替、属性/スロット絞込、スキル3つ、カオスオーブ、倍速/AUTO/周回/DPS/撤退、強化/装備/出撃ボタン、下部5タブナビ）はすべて画面下半分に集中配置。
  - 右利き／左利きレイアウト切替に対応（`save.settings.handedness`）。

## 3. 実装済みゲーム仕様（維持必須）

### 3.1 属性・属性相性（6種）
- 順序: **炎(`fire`) → 水(`water`) → 風(`wind`) → 光(`light`) → 闇(`dark`) → 無(`none`)**
- 相性 (`getElementMultiplier`):
  - 炎 → 風 (1.5x) / 水 (0.75x)
  - 水 → 炎 (1.5x) / 風 (0.75x)
  - 風 → 水 (1.5x) / 炎 (0.75x)
  - 光 ⇔ 闇 相互弱点 (1.5x)
  - 無: 全属性等倍 (1.0x) ＋ カオスゲージ獲得率 +25%

### 3.2 種族・2種族持ち・種族共鳴（5種）
- 順序: **人間(`human`) → 竜(`dragon`) → 魔物(`monster`) → 妖精(`fairy`) → 機械(`machine`)**
- 2種族持ちユニットが存在（2種族目は常に第1種族より後の順で格納）。
- 種族共鳴（パーティ内2体/3体で発動、2種族持ちは両方のカウントに加算）。

### 3.3 ロール・ロール固有アビリティ（4種）
- 順序: **タンク(`tank`) → ディーラー(`dealer`) → サポーター(`supporter`) → ヒーラー(`healer`)**
- アビリティ:
  - タンク『鉄壁の挑発』: 被狙われ率増・被ダメ20%減・被弾時味方全体小シールド
  - ディーラー『追撃の極意』: 弱点/会心時に35%追撃・攻撃ごと与ダメ累積(最大+30%)
  - サポーター『時空干渉』: 行動開始時最遅味方のゲージ+18%加速・バフ/デバフ持続+1T
  - ヒーラー『生命の奔流』: 回復量+25%・超過回復をシールド変換・回復時弱体1つ解除

### 3.4 ユニット並び替え規則（絶対厳守）
`src/engine/sort.ts` の `compareUnits` にて以下を厳密適用：
1. 属性順: 炎 → 水 → 風 → 光 → 闇 → 無
2. 種族順: 第1種族（人間→竜→魔物→妖精→機械）→ 第2種族（単独(-1)→人間→竜→魔物→妖精→機械）
   - 例: 人間 → 人間・竜 → 人間・魔物 → 人間・妖精 → 人間・機械 → 竜 → 竜・魔物 …
3. ロール順: タンク → ディーラー → サポーター → ヒーラー

### 3.5 ユニット・技・装備・専用武器
- **全24体**（6属性×4ロール、単一種族＋2種族持ち13体）。初期4体（バルド・ミオ・シルフ・ルナ）。
- 各キャラ **技3つ**（基本技 CT0 / 戦術技 / カオス奥義）。
- **汎用装備3枠**（武器・防具・装飾、レアリティ N/R/SR/SSR/CHAOS、ランダムサブオプション、Lv20強化、ロック、売却）。
- **専用武器（各キャラ固有1枠）**: 鍛造（G+結晶+専用核）＆覚醒Lv10強化でステータス大幅上昇＋固有パッシブ発動。
- **自動売却**: OFF / N以下 / R以下 / SR以下を設定可能。ドロップ時に自動換金（G＋強化粉）しリザルトへ集計。

### 3.6 戦闘・はちゃめちゃ要素・操作・リザルト
- **操作**: タップ ＋ Pointer Events ベースのドラッグ＆ドロップ（iOS Safari対応）。
  - 戦闘中: スキルボタンを敵/味方へドラッグしてターゲット指定＋即発動、カオスオーブを敵（崩壊砲）または味方（全体超覚醒）へドラッグ発動。
  - 編成中: ユニットをパーティ4枠へドラッグ＆ドロップで入替。
- **行動順タイムライン**: `predictTimeline` で次6手先まで常時表示。
- **カオスゲージ＆6種の混沌法則**: 100%到達でランダム法則発動＋カオスオーブ装填。
- **戦闘速度**: `1x / 2x / 3x`（最大3倍速）。
- **自動バトル & 無限自動周回**: AUTO切替、無限自動周回（勝利後インターバルバナー→自動次戦、敗北時または停止操作で周回累計リザルトへ）。
- **リザルト2種**:
  - 通常リザルト（勝敗・報酬・LvUP・ドロップ・自動売却内訳・4指標DPS）
  - 周回リザルト（総周回数・勝率・平均時間・累計報酬・自動売却合計・確保装備・累計4指標DPS）
- **DPSメーター**: **与ダメ・被ダメ・与回復・被回復** の4指標をリアルタイム＆リザルトで切替表示。
- **PvEコンテンツ4種**: 混沌の旅路(12ステージ) / 無限塔(エンドレス生成) / 異界ボス(4体) / 素材収集(3種・常時開放)。

## 4. 技術スタック・開発コマンド

- **構成**: Vite 6 + TypeScript + Preact + vite-plugin-pwa + Pure CSS + Web Audio API 合成SE
- **ビルド**: `npm run build`（Windows PowerShellでスクリプト制限時は `npm.cmd run build`）
- **ローカルプレビュー**: `npm run preview -- --port 4298 --host 127.0.0.1`
  - ※同一ポートで別PWAのService Workerキャッシュが残っていると旧アプリが返るため、検証時は未使用ポートを使うこと。
