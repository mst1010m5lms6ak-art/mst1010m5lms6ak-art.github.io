# 【はちゃめちゃ世界】次回指示用 引継ぎ仕様書（HANDOVER_SPEC）

> **重要**: 次回以降の改修・機能追加を行うAI／開発者は、コード編集前に必ず本書と [CODE_MAP.md](./CODE_MAP.md) を確認し、**既存仕様を消さないこと**および**絶対禁止事項を破らないこと**を厳守すること。

## 1. 絶対禁止事項（NEVER DO）

1. **ガチャ禁止**：確率排出・ガチャ演出・課金ガチャ石は一切実装しない。仲間はステージ攻略・混沌結晶＆ゴールド消費の「確定解放」のみ。
2. **時間縛り日課禁止**：デイリー・ウィークリー・マンスリーミッション、ログインボーナス、スタミナ時間回復制限は一切実装しない。
3. **PvP禁止**：対人戦・ランキング・ギルド・マルチプレイは一切実装しない。完全ソロPvE完結。
4. **キャライラスト禁止**：キャラ立ち絵や重い画像アセットを追加しない。ユニット表現は幾何学SVG紋章（`js/ui-svg.js`）＋属性オーラ＋ロール記号＋Canvas2Dエフェクトのみで完結させる。
5. **開発メタ発言・設定説明文の撲滅**：ゲーム内テキストに「開発」「実装」「〇〇は1行固定」「親指ゾーン」「バグ」などのメタ発言・仕様書そのままの文言を絶対に入れない。
6. **画面上半分（`#top-display`）への操作配置禁止**：タップ・ボタン・切替・閉じる操作はすべて画面下半分（`#bottom-control`）または下部展開ボトムシート（`#sheet-panel`）内にのみ配置する。上部は閲覧専用。
7. **戦闘中の他画面移動禁止**：戦闘中およびリザルト表示中（`HS.BATTLE.getCurrent() !== null`）は `#app-shell.battle-mode` により `#bottom-nav` を非表示にし、`nav-tab` アクションを拒否する。撤退は明示確認シート経由のみ。
8. **微妙なスクロール＆見切れ禁止**：`html, body, #app-root, #app-shell` は `100dvh` 固定・`overflow: hidden`。スクロールは `.scroll-y` / `.scroll-x` を持つ一覧コンテナ内部のみ許可。375×667（iPhone SE）および 393×852（iPhone 15 Pro）の双方でクリップ・はみ出し0pxを維持すること。
9. **4倍速以上禁止**：戦闘速度は `1倍速 / 2倍速 / 3倍速` の上限3倍速を厳守する。
10. **`dist` ビルド必須化・ES Module CORS破壊禁止**：ビルド不要の通常 `index.html` で `file://` 直接起動・GitHub Pages・Capacitor のすべてが動くよう、`<script defer>`＋`window.HS` 名前空間構成と相対パス `./` を維持する。
11. **ファイル数100件上限**：リポジトリ総ファイル数は100ファイル以内（現在28ファイル）を維持し、外部ライブラリや重い画像・音声ファイルを追加しない（容量軽量化厳守）。

## 2. アーキテクチャ・PWA・iOS/Capacitor 要件

- **構成**：No-Build Vanilla HTML / CSS / JavaScript + インラインSVG + Canvas2D + Web Audio API 合成SE。
- **名前空間**：全JSモジュールは IIFE 内で `window.HS`（`CONST`, `CHARS`, `STAGES`, `EQUIP`, `STORAGE`, `AUDIO`, `SVG`, `DRAG`, `FX`, `BATTLE`, `UI_BATTLE`, `UI_SCREENS`）に登録。
- **PWA / オフライン**：
  - `manifest.webmanifest`（`display: standalone`, `orientation: portrait`, 相対パス）
  - `sw.js`（Cache-First。ファイル変更・追加時は `CACHE_NAME` のバージョン番号を上げ、`ASSETS` 配列を更新すること）
  - `icons/icon-180.png`（iOS `apple-touch-icon` 必須実PNG）, `icon-192.png`, `icon-512.png`, `icon.svg`
- **iOS Safari セーフエリア＆誤操作防止**：
  - `viewport-fit=cover`, `apple-mobile-web-app-capable=yes`, `apple-mobile-web-app-status-bar-style=black-translucent`
  - `#app-shell` に `padding: env(safe-area-inset-*)`
  - `-webkit-touch-callout: none`, `-webkit-user-select: none`, `-webkit-user-drag: none`, `touch-action: none`（スクロール対象のみ `pan-y` / `pan-x`）、`gesturestart`・ダブルタップ拡大防止。
- **オフラインデータ保存**：`localStorage`（キー：`hachamecha_sekai_save_v1`）＋ `IndexedDB`（`HachamechaSekaiDB`）自動バックアップ＋JSON書き出し/読み込み。
- **Capacitor 前提**：`capacitor.config.json` 同梱（`webDir: "."`、`ios.scrollEnabled: false`、`ios.allowsLinkPreview: false`）。

## 3. 実装済みゲーム仕様一覧（維持必須）

### 3.1 属性・属性相性
- 6属性：`炎(fire)` / `水(water)` / `風(wind)` / `光(light)` / `闇(dark)` / `無(none)`
- 三すくみ：**炎 → 風 → 水 → 炎**（有利1.35倍 / 不利0.75倍、カオス法則「属性暴走」時は有利1.85倍）
- 対極：**光 ⇔ 闇**（相互1.30倍）
- **無**：等倍（カオス法則「無律覚醒」時は与ダメ1.40倍）

### 3.2 種族・2種族持ち・種族シナジー
- 5種族：`人間(human)` / `竜(dragon)` / `魔物(demon)` / `妖精(fairy)` / `機械(machine)`
- 2種族持ちキャラは両種族カウントに加算され、複数シナジーを同時発動可能。
- 同種族2体以上で段階強化（2/3/4体）。さらに4属性以上混成で「混沌四彩」、同属性3体以上で「〇〇共鳴」が発動。

### 3.3 ロール・ロール固有アビリティ・3技・専用武器
- **タンク**：鉄壁の挑発（狙われ率UP・開幕HP22%障壁・被弾時カオス+5）
- **ディーラー**：狂乱の追撃（会心威力+25%・撃破時行動+35%・25%確率で追撃）
- **サポーター**：混沌の共振（付与バフ+1T延長・行動時に味方1体のCTを1短縮）
- **ヒーラー**：生命の余剰（超過回復を障壁変換・回復時に弱体1つ浄化）
- 全24キャラ実装済み（初期解放6体、残18体は確定解放）。全員 **技3つ（技1・技2・奥義）**＋**固有の専用武器（Lv1〜5覚醒）** を保有。

### 3.4 厳密なキャラクター並び順（ソート仕様）
`HS.CONST.getCharSortKey(ch)` および `HS.CONST.sortCharacters(list)` により全一覧で厳密統一：
1. **属性**：`炎(0) → 水(1) → 風(2) → 光(3) → 闇(4) → 無(5)`
2. **種族**：第1種族 `人間(0) → 竜(1) → 魔物(2) → 妖精(3) → 機械(4)`、第2種族 `単体(0) → 人間(1) → 竜(2) → 魔物(3) → 妖精(4) → 機械(5)`
   - 例：`人間 → 人間・竜 → 人間・魔物 → 人間・妖精 → 人間・機械 → 竜 → 竜・魔物 → …`
3. **ロール**：`タンク(0) → ディーラー(1) → サポーター(2) → ヒーラー(3)`

### 3.5 はちゃめちゃ戦闘・ログ・DPSメーター・2種リザルト
- **行動順表示**：現在ATBと実効速度から次6手の行動順をリアルタイム予測表示。
- **はちゃめちゃ要素**：カオスゲージ100%到達で8種のランダム【カオス法則】発動＆味方全員連動の【はちゃめちゃバースト】解禁。
- **操作**：タップおよび Pointer Events によるドラッグ＆ドロップ（編成スロット入替・装備装着・手動スキル→敵ターゲット）。
- **戦闘ログ**：`height: 21px`（低画面`18px`）・`white-space: nowrap; overflow: hidden; text-overflow: ellipsis;` の1行固定構造により、2行折り返しによるズレ・消え残りを構造的に防止。誰が誰に何をしたか色分け表示。
- **DPSメーター（4指標）**：戦闘中・通常リザルト・周回リザルトすべてで **与ダメージ (`dealt`) / 被ダメージ (`taken`) / 与回復量 (`healOut`) / 被回復量 (`healIn`)** を親指タブで即切替。
- **通常リザルトと周回リザルトの完全分離**：
  - `result_normal`（通常リザルト）：1戦の報酬・レベルアップ・4指標詳細（シェア%付）・ドロップ装備のその場保護/売却・再戦/帰還。
  - `result_loop`（周回リザルト）：周回数・勝敗・平均クリア秒・累計G/結晶/核・自動売却累計件数＆換金額・累計4指標メーター・周回で確保した装備一覧・次戦カウントダウンゲージ・一時停止/再開/今すぐ次戦/周回終了。
- **無限自動周回＆自動売却**：敗北または手動停止まで無限周回。レアリティ閾値（OFF / N以下 / R以下 / SR以下 / SSR以下）でロック・装備中以外を自動売却＆一括売却。

### 3.6 PvE コンテンツ（4モード）
1. **混沌紀行 (`journey`)**：全5エリア×5戦＝25ステージ（各エリア5戦目は領域ボス＆領域法則）。
2. **カオス深淵 (`abyss`)**：1F〜無限階層タワー（5Fごとに階層主ボス、勝利で次階層解放）。
3. **異端試練 (`trial`)**：5種の高難度ボス戦（専用武器解放素材「混沌核」確定入手）。
4. **カオス乱闘 (`rush`)**：3種のボスラッシュ（装備大量ドロップ周回用）。
