# 『はちゃめちゃ世界』引継ぎ用仕様書（HANDOVER_SPEC）

本ドキュメントは、次回以降の改修・機能追加で**実装済み機能を破壊しないこと**、および**絶対禁止事項を誤って実装しないこと**を保証するための公式仕様書です。

---

## 1. 絶対禁止事項（NEVER IMPLEMENT）

以下の要素はいかなる理由があっても追加・変更してはならない。

1. **ガチャ禁止**: キャラ・装備・専用武器のガチャ／課金抽選システムを一切実装しない。入手経路は PvE ステージ初回クリア・ボス討伐・ドロップ・魂片交換のみ。
2. **日課・期限ミッション禁止**: デイリー／ウィークリー／マンスリーミッション、ログインボーナス連続日数、スタミナ回復待ちを実装しない。
3. **PvP・マルチ禁止**: 対人戦・ランキング・ギルド義務を実装しない（完全ソロ PvE 専用）。
4. **キャライラスト禁止**: キャラ立ち絵・顔画像・SVG人物イラスト・外部画像アセットを追加しない。属性色×種族×ロール記号の幾何学エンブレム表現を維持する。
5. **ゲーム内メタ発言・設定文の露出禁止**: 画面表示テキストに開発メタ用語（「1行固定」「親指ゾーン」「セーフエリア」「容量軽量化」「ガチャなし」「iOS対応」等）や仕様説明そのままの文言を出さない。
6. **`dist/` ビルド導入禁止**: ビルド必須構成（Webpack/Vite等による `dist/` 出力前提）にしない。ルートの `index.html` をそのまま開いて動作する Vanilla HTML/CSS/JS 構成を維持する。
7. **画面上半分への操作要素配置禁止**: `#upper-zone`（画面上部約47%）にはボタン・タブ・閉じる `×` 等の操作要素を一切置かない（CSS側でも `pointer-events: none` で固定済み）。モーダル／シートの操作・閉じるボタンも必ず下端 `.sheet-foot` に配置する。
8. **微妙なスクロール発生・見切れ禁止**: `#app-frame`, `#upper-zone`, `#lower-zone`, `#upper-content`, `#lower-content` 等の固定枠で `scrollHeight > clientHeight` や横はみ出しを作らない。スクロールは `.scroll-box` 内のリストのみ許可。
9. **戦闘中の他画面移動許可禁止**: `HS.COMBAT.isActive()` が `true` の間、下部ナビの `編成 / 育成 / 装備 / 記録` タブは必ずロックし遷移させない（パーティ人数変更による敗北・状態不整合防止）。
10. **4倍速以上禁止**: 戦闘倍速は `SPEED_STEPS = [1, 2, 3]`（最大3倍速）を厳守する。
11. **通常リザルトと周回リザルトの統合禁止**: 単発戦闘終了の「通常戦闘リザルト」と、無限自動周回終了の「∞ 無限自動周回 集計リザルト」は必ず別UI・別フローを維持する。
12. **戦闘ログの2行折り返し禁止**: `.log-row` は厳密な固定1行（`height: 22px; white-space: nowrap; overflow: hidden;`）を維持し、スクロール／消滅ズレを起こさない。
13. **総ファイル数100超過禁止**: プロジェクト全体（ドキュメント・アイコン含む）を100ファイル以内に収める（現在 **32ファイル / 約300KB**）。

## 2. 厳守すべきコア仕様（実装済み機能一覧）

### 2.1 iOS Safari (PWA) & Safe Area・操作性
- `viewport-fit=cover` + `100dvh` + `position: fixed; inset: 0` によるラバーバンドスクロール完全抑止。
- `#app-frame` に `env(safe-area-inset-top/bottom/left/right)` を適用し、ノッチ・Dynamic Island・ホームバーとの干渉を防止。背景（`#app-shell`）はフルブリード表示。
- `-webkit-touch-callout: none`、`-webkit-user-select: none`、`touch-action: manipulation`（ドラッグ対象は `touch-action: none`）、`gesturestart`/`gesturechange` 抑止、入力欄 `font-size: 16px` 固定。
- 縦画面基準（`max-width: 480px` 中央配置）で iPhone SE (375×667)〜Pro Max (430×932)・iPad・PC でレイアウト崩壊ゼロ。
- `sw.js` は **Network-First + Offline Cache Fallback**（オンライン時は最新反映、オフライン時はキャッシュ起動）。ファイル追加・変更時は `sw.js` の `CACHE_NAME` と `PRECACHE_ASSETS` を必ず更新すること。

### 2.2 キャラ・属性・種族・ロール・厳格ソート順
- **全21体**（初期加入4体: カグラ・シズク・ハヤテ・リル／残り17体はステージ・ボス初クリアまたは魂片30で加入）。
- **属性（6種）と相性**: `炎(0) < 水(1) < 風(2) < 光(3) < 闇(4) < 無(5)`
  - 炎＞風＞水＞炎（有利 `1.35x` / 不利 `0.75x`）
  - 光⇄闇（相互弱点 `1.30x`）
  - 無（相性なし `1.0x`・編成すると混沌ゲージ蓄積加速）
- **種族（5種・2種族持ちあり）**: `人間(0) < 竜(1) < 魔物(2) < 妖精(3) < 機械(4)`
  - 2種族持ちは両方の種族シナジーへ同時カウントされる。
- **ロール（4種・各ロール固有アビリティあり）**: `タンク(0) < ディーラー(1) < サポーター(2) < ヒーラー(3)`
  - タンク: 守護の楔 / ディーラー: 混沌追撃 / サポーター: 加速共鳴 / ヒーラー: 再生の波動
- **厳格ソート順（`HS.CONST.sortUnitsCanonical`）**:
  1. 属性（炎→水→風→光→闇→無）
  2. 主種族（人間→竜→魔物→妖精→機械）
  3. 第2種族（なし `-1` → 人間 `0` → 竜 `1` → 魔物 `2` → 妖精 `3` → 機械 `4`）※例: `人間 → 人間・竜 → 人間・魔物`
  4. ロール（タンク→ディーラー→サポーター→ヒーラー）
  - ※2種族キャラの `races` 配列は必ず昇順で定義すること。
- **技・専用武器**: 各キャラ技3種（CD管理）＋固有の専用武器（星屑コア＋魂片＋Gで解放・Lv.5覚醒・戦闘パッシブ実装済み）。

### 2.3 はちゃめちゃ戦闘・周回・ログ・DPS
- **ATB行動順表示**: 上部 `order-bar` に次の行動者6体を均等幅で表示。
- **はちゃめちゃ異変（5種）**: 混沌ゲージ100%で「重力反転メテオ」「倍々カオスフィーバー」「属性シャッフル暴走」「時空バグ加速」「大回復パレード」が発動。
- **操作**: タップ＋Pointer Events 統合ドラッグ＆ドロップ（編成スロット配置/入替/解除、装備スロット装着/売却、戦闘中スキルのターゲット指定ドロップ、カオスオーブ解放）。
- **戦闘ログ**: 誰が誰に何をしたか分かる固定1行（`22px`）表示。ライブ3行常時表示＋上部切替で詳細ログ（最新7件・フィルタ4種）。
- **4指標DPSメーター**: 与ダメージ(`dmgDealt`)・被ダメージ(`dmgTaken`)・与回復量(`healDone`)・被回復量(`healRecv`)を戦闘中・通常リザルト・周回集計リザルトの全3箇所で下部ボタンから切替可能。
- **無限自動周回 & 自動売却**: 勝利後1.15秒で次戦自動開始（無限塔は自動階層進行）。ドロップ装備は自動売却ルール（レアリティ上限・高評点保護・ロック/CHAOS保護）に基づき自動でG＆魔粉へ変換。
- **PvEコンテンツ**: 冒険5章×4面（20面）、属性ボス6体、無限カオス塔（1F〜∞）、オフライン探索報酬（最大12時間）。

### 2.4 データ保存・公開・Capacitor移行
- **二重オフライン保存**: IndexedDB (`HachamechaSekaiDB`) + `localStorage` (`hachamecha_sekai_save_v1`) + `navigator.storage.persist()` + セーブコード書き出し／読み込み。
- **GitHub Pages公開**:
  - Branch公開: リポジトリにアップロード → Settings → Pages → Branch `main` / `/ (root)`（`.nojekyll` 同梱済み）。
  - GitHub Actions公開: Settings → Pages → Source を `GitHub Actions` に設定（`.github/workflows/deploy-pages.yml` 同梱済み）。
- **Capacitor iOS 移行手順**:
  - `capacitor.config.json`（`webDir: "www"`）配置済み。iOSアプリ化時は `index.html`, `manifest.webmanifest`, `sw.js`, `css/`, `js/`, `icons/` を `www/` へコピーして `npx cap sync ios && npx cap open ios` を実行する（`webDir: "."` にすると `ios/` フォルダ再帰コピー事故になるため `www` 経由が安全）。

## 3. 新機能追加時のチェックリスト
- [ ] 上半分（`#upper-zone`）にボタンを置いていないか？
- [ ] `375×667` と `393×852` で意図しないスクロール・見切れが発生していないか？
- [ ] キャラを追加した場合、`races` が昇順であり `HS.CONST.sortUnitsCanonical` で正しく並ぶか？
- [ ] 新しいJS/CSSファイルを追加した場合、`index.html` の `<script defer>` 順と `sw.js` の `PRECACHE_ASSETS`＆`CACHE_NAME` を更新したか？
- [ ] 既存セーブデータとの後方互換性を `js/game/state.js` の `mergeSave()` で維持しているか？
- [ ] 禁止事項（ガチャ・日課・PvP・キャライラスト・メタ発言・4倍速以上・戦闘中移動許可）に触れていないか？
